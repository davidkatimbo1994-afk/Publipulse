# PubliPulse Pilot Measurement Plan

## Objective

Evaluate whether the PubliPulse outcome/accountability overlay changes workflow completeness and district review decisions when used alongside an existing detection/event-management system.

## Comparison

Use the existing workflow as the baseline and compare it with the PubliPulse-supported workflow over a predefined pilot period. Do not pool incompatible definitions across systems; document the exact denominator and timestamp definition for every measure.

## Primary implementation measures

- signal → ownership completion;
- ownership → action start;
- action → outcome measurement;
- proportion closed without resolution evidence;
- proportion with explicit outcome status;
- recurrence after action;
- median time to measured outcome;
- open Action Gap burden;
- frequency of normalized response blockers;
- weekly review decisions attributable to information surfaced by the overlay.

## Guardrails

These measures are descriptive implementation outcomes. They do not establish clinical effectiveness, causation, outbreak status, or superiority over another system without an appropriate comparative study design.

## Minimum pilot evidence

The pilot record should include: baseline definitions, data-source mapping, approved cohort boundaries, weekly review artifacts, unresolved/recurrence decisions, offline-sync incidents, integration failures, privacy incidents, and a final comparison report.
