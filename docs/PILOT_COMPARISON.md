# Pilot Comparison

## Purpose

The pilot comparison endpoint provides a structured descriptive comparison between a documented baseline period and a PubliPulse-supported pilot period.

## Required windows

Both periods require explicit start/end timestamps. The periods should use compatible cohort definitions, source boundaries, and timestamp definitions. Do not compare incompatible denominators.

## Measures

- verification completeness;
- ownership completeness;
- action completeness;
- outcome-measurement completeness;
- durable-outcome completeness;
- unresolved burden;
- pending durability;
- blocker burden.

## Interpretation

The endpoint reports implementation differences. It does not establish causation, clinical effectiveness, outbreak control, or superiority over an existing tool.

A pilot team should retain the baseline definition, source mapping, cohort boundaries, weekly review artifacts, integration/offline incidents, privacy incidents, and final comparison alongside the reported values.
